Where are my game files?

In Steam, open Doom 3's installed files with Browse, then select its base folder. You can also select all nine .pk4 files directly.

A typical Windows location is Steam/steamapps/common/Doom 3/base. Use the original Doom 3 installation; BFG Edition and expansion files aren't supported.

Choosing game archives replaces the previous set. An empty or unrelated selection keeps your loaded files. Loading large archives may take a moment.

2Launch Doom 3
